# Artha v0.6 launch checklist

## 1. Local setup

```powershell
cd D:\HarishProjects\Artha
Copy-Item .env.local.example .env.local
npm install
npm run dev
```

Set the Supabase project URL and publishable key in `.env.local`.

For local AI:

```powershell
ollama pull gpt-oss:20b
npm run ai
```

The browser automatically uses `http://localhost:8787/api/coach` when running on localhost unless `NEXT_PUBLIC_AI_ENDPOINT` is set.

## 2. Supabase database

Run:

```text
supabase/migrations/001_artha_v06.sql
```

in the Supabase SQL Editor.

Expected tables:

- profiles
- income
- expenses
- investments
- loans
- insurance
- goals
- transactions
- ai_usage

## 3. Auth URLs

Add these to Supabase Auth URL Configuration:

```text
http://localhost:3000/auth
https://harishsarmav.github.io/artha/auth
```

Site URL for local development:

```text
http://localhost:3000
```

The GitHub Pages build sets `/artha` as its public base path and sends email confirmation back to `/artha/auth`.

## 4. Production AI gateway

Deploy the function:

```powershell
supabase functions deploy artha-ai
```

Configure production secrets in Supabase Edge Function secrets:

```text
AI_PROVIDER=openai_compatible
AI_BASE_URL=https://api.openai.com/v1
AI_MODEL=YOUR_MODEL
AI_API_KEY=YOUR_SERVER_SIDE_KEY
```

The gateway applies a 30-request-per-user-per-day AI quota. Deterministic dashboard calculations do not require an AI provider.

## 5. GitHub Pages variables

Create repository Variables under GitHub → Settings → Secrets and variables → Actions → Variables:

```text
NEXT_PUBLIC_SUPABASE_URL
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY
NEXT_PUBLIC_AI_ENDPOINT=https://YOUR_PROJECT.supabase.co/functions/v1/artha-ai
```

Never store `AI_API_KEY` in GitHub Pages variables or any `NEXT_PUBLIC_*` variable.

## 6. Acceptance tests

### Auth

- Create a new account.
- Confirm the email.
- Sign in.
- Refresh the page.
- Sign out.
- Sign back in and confirm the same data is still present.

### Profile

- Edit profile values.
- Save.
- Refresh and confirm persistence.
- Reopen Account & security and confirm the signed-in email is displayed.
- Change password and sign in again with the new password.

### Financial data

- Add at least one income source.
- Add recurring expenses.
- Add an investment.
- Add a loan.
- Add an insurance policy.
- Add a financial goal.
- Add a transaction.
- Edit and delete one row from each section.

### Financial Engine

- Confirm monthly normalization works for Weekly, Quarterly, Half-yearly and Yearly records.
- Confirm loan EMI is counted once.
- Confirm emergency-fund coverage changes when liquid savings change.
- Confirm goal required monthly contribution changes with the target date.
- Confirm tracked net worth = cash savings + current investments − outstanding debt.

### AI

- Ask a normal coach question.
- Run a financial review.
- Run the savings scenario.
- Auto-categorize a transaction.
- Temporarily remove the AI key and confirm deterministic fallback responses still work.
- Confirm the 31st AI request in one day returns the daily-limit message.

### GitHub Pages

- Push to `main`.
- Confirm the Actions workflow completes.
- Open `https://harishsarmav.github.io/artha/`.
- Sign in from the deployed site.
- Confirm email confirmation returns to `/artha/auth`.
- Confirm the AI Coach uses the deployed Edge Function.
